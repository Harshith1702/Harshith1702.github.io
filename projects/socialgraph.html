Social Follower Graph (C)

A console follower system in C with follow and unfollow operations, mutual-follow suggestions, and file persistence.

GitHub ↗

About the project

  1. 01

    Models follower relationships with an adjacency matrix and keeps users in an array of strings.

  2. 02

    Supports user search, follow and unfollow, follower lists, and mutual-follow suggestions.

  3. 03

    Loads users and relationships from text files and saves updates.

  4. 04

    An educational console prototype with a fixed maximum user count and no authentication.

LeetCode Grind Tracker

The DBMS project that preceded GrindLens: a submission sync script, MySQL views, a PHP API, and a JavaScript dashboard.

GitHub ↗

About the project

  1. 01

    A Python sync script fetches LeetCode submissions through alfa-leetcode-api and stores them in MySQL.

  2. 02

    SQL views calculate difficulty breakdowns, topic accuracy, and streak history.

  3. 03

    A PHP endpoint serves the views as JSON to a dashboard with four tabs.

  4. 04

    The upstream endpoint returns the latest 50 submissions. Earlier history is unavailable, and topics default to Unknown until updated.

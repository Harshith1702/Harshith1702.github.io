SERVICE MONITOR

Midnight Network

An HTTP service monitor that stores checks in SQLite and opens and closes incidents as services fail and recover.

Website ↗GitHub ↗

About the project

  1. 01

    Checks each service on its configured interval and stores status codes, response times, and errors.

  2. 02

    A failed check opens an incident. The next successful check closes it and records the downtime.

  3. 03

    Services, history, and open incidents persist across restarts in SQLite.

  4. 04

    A single-worker monitor without authentication or alerts. HTTP status below 400 counts as up; redirects are not followed.

Built with

  • Python
  • Flask

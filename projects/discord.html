DISCORD AUTOMATION

LeetCode Discord Reporter

I built this bot to replace copying solved problem links into our daily training group. It posts accepted LeetCode submissions to Discord at 10:15 PM IST through cron-job.org and GitHub Actions. Session cookies need refreshing roughly every two weeks.

GitHub ↗

About the project

  1. 01

    Queries the LeetCode GraphQL recentAcSubmissionList endpoint for accepted submissions.

  2. 02

    Checks submission timestamps against a daily IST window.

  3. 03

    Posts difficulty statistics through a Discord webhook.

  4. 04

    Runs at 10:15 PM IST through cron-job.org and GitHub Actions.

  5. 05

    LeetCode session cookies need refreshing roughly every two weeks.

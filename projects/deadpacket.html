Dead Packet Detective

A network-forensics workbench that collects DNS, ping, TCP handshake, and route evidence for a hostname or IP.

GitHub ↗

About the project

  1. 01

    Runs probes locally and shows the exact commands and raw evidence as they finish.

  2. 02

    Separates confirmed observations from hypotheses, next steps, and limitations.

  3. 03

    Exports a Markdown case file with reproduction commands.

  4. 04

    Uses the Python standard library and system networking tools. It does not capture packets or analyze PCAP files. Cases stay in memory until exported.

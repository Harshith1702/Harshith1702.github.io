## Design decisions

- Width: a 700px reading column preserves the editorial direction and leaves enough room for two real project previews at tablet widths.
- Breakpoint: 740px is where the available column can support two approximately 300px project cards, rather than forcing two columns at a generic device breakpoint.
- Typography: retained Geist for reading and Geist Mono for source metadata, stacks, and date ranges. No new typeface or visual identity was introduced.
- Color: retained the existing neutral palette; changed muted dark text only to make the audited labels readable.
- Preview: Midnight's workflow explains its actual distinguishing behavior without pretending to be a running monitor.
- Skills: plain domain groups make tools easier to scan and remove inaccurate symbols.
- Interaction: More builds remains a native closed-by-default disclosure. Project cards retain relative .html destinations and direct external links.
- Preservation: the companion's script prefix, protected element tags, and original style.css matched the before-edit snapshot. Existing portfolio.css lines were unchanged; new rules do not target protected companion selectors.
